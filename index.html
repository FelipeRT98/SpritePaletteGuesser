Sprite Palette Guesser

Load your own sprites to play. Files are read locally by your browser and are never uploaded.

Option 1 - Folders

Choose a folder with the original sprites and a folder with their color maps (the clue shown to the player). Files are paired by name, ignoring the extension, e.g. image_name.png in both folders. That name is the answer. Accepted: PNG, GIF, WebP, JPG, BMP. Subfolders are included.

Option 2 - JS file

Choose a .js (or .json) file that declares one object. Each key is the answer; each value has an image and a colorMap, both as data URLs (or image URLs): 

const myData = {
  "image_name": {
    image: "data:image/png;base64,…",
    colorMap: "data:image/png;base64,…",
  },
};

Only load files you trust: the page runs the file's code.
